## Moving between cells

| Key | Does |
| --- | --- |
| <kbd>j</kbd> <kbd>k</kbd> | Next / previous cell; with a count, `3j` moves three |
| <kbd>g</kbd><kbd>g</kbd> <kbd>G</kbd> | First / last cell |
| <kbd>5</kbd><kbd>G</kbd>, `:5` | Go to cell 5 |
| <kbd>Ctrl</kbd>+<kbd>o</kbd> <kbd>Ctrl</kbd>+<kbd>i</kbd> | Jump back / forward |
| <kbd>z</kbd><kbd>t</kbd> <kbd>z</kbd><kbd>z</kbd> <kbd>z</kbd><kbd>b</kbd> | Scroll so the selected cell is at the top / middle / bottom of the screen |
| mouse click | Select a cell |
| mouse wheel | Scroll the notebook |

### Jumping back

As in vim, the bigger moves are *jumps*: <kbd>g</kbd><kbd>g</kbd>, <kbd>G</kbd>, <kbd>5</kbd><kbd>G</kbd>, `:5`, and going to a search match with <kbd>/</kbd>, <kbd>n</kbd> or <kbd>N</kbd>. jOtter remembers the cell you jumped from, so <kbd>Ctrl</kbd>+<kbd>o</kbd> takes you back there, and further back through earlier jumps. <kbd>Ctrl</kbd>+<kbd>i</kbd> goes forward again. Stepping with <kbd>j</kbd> and <kbd>k</kbd> isn't a jump. The list follows cells, not positions: after moving or inserting cells, <kbd>Ctrl</kbd>+<kbd>o</kbd> still finds the cell you were on, and skips cells you deleted.

Most terminals send <kbd>Ctrl</kbd>+<kbd>i</kbd> as <kbd>Tab</kbd>, so <kbd>Tab</kbd> jumps forward too.

<kbd>z</kbd><kbd>t</kbd>, <kbd>z</kbd><kbd>z</kbd> and <kbd>z</kbd><kbd>b</kbd> work as in vim, on the whole cell instead of the cursor line. A cell taller than the screen always shows its top.

The view scrolls to keep the selected cell visible. Scrolling with the wheel doesn't move the selection. If the wheel is over a long output, it scrolls that output first; see [Outputs](/jotter/guides/outputs/#long-outputs).

## Marks

Marks work as in vim, on cells: <kbd>m</kbd> then a letter (<kbd>m</kbd><kbd>a</kbd>) marks the selected cell as `a`, and <kbd>'</kbd><kbd>a</kbd> (or <kbd>&#96;</kbd><kbd>a</kbd>) jumps back to it from anywhere. Marking another cell with the same letter moves the mark. A mark jump is a [jump](#jumping-back), so <kbd>Ctrl</kbd>+<kbd>o</kbd> returns to where you were.

The marked cell's header shows its letter (`In [3] 'a`), and while any marks are set, a **Marks** sidebar on the right lists them in notebook order: letter, cell number and the cell's first line, with the selected cell's marks highlighted. The sidebar needs a terminal at least 80 columns wide; in a narrower one only the header letters show.

A mark follows its cell when cells move. Deleting the cell removes its mark, and undoing the delete brings it back. `:delm a` deletes mark `a` (`:delm abc` several), and `:delm!` deletes them all. Marks last for the session; they aren't saved in the notebook.

## Searching

Press <kbd>/</kbd>, type text and press <kbd>Enter</kbd>. jOtter selects the next cell whose source contains it, ignoring case. <kbd>n</kbd> and <kbd>N</kbd> go to the next and previous match, wrapping around the notebook.

Search looks at cell sources only, not outputs.

| <kbd>L</kbd> | Show the log: jOtter's and the kernel's messages from this session |
